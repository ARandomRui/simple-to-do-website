# simple-to-do-website
A free to use, no sign up/log in needed, simple to-do list website. Recommended to show on startup.
- Able to create more lists 
- Able to give description/further thoughts on tasks.
- Considering making it superbase compatible someday... to sync accross devices

How to add to "On Startup":
1. Click on the 3 dots on the upper right (On Chrome)
2. "Settings" > "On Startup" > "Open a specific page or set of pages" > put the link
